# 知识库建立与管理

> 本文档完整说明如何从零建立一个「个人文学知识库」并长期维护它。这套规范是诗云系统的数据基础——诗云（`../server.js`）直接读取 `wiki/归档/诗集` 与 `wiki/赏析` 两个目录。

---

## 1. 核心理念

- **写作区与归档区分离**：`raw/` 只写不归档，`wiki/归档/` 只归档不手编
- **复制而非移动**：归档时把文件复制到归档区，源文件永远保留
- **双维度归档**：每首作品同时出现在「语言 → 主题」与「年份 → 语言 → 主题」两个维度，任何角度都能找到
- **元数据驱动**：一切分类都来自 frontmatter（theme / form / created），不靠目录名猜
- **AI 辅助但可审计**：Agent Skill（ingest / query / lint）自动化重复劳动，但所有写入都经过确认并留日志

## 2. 目录结构

```
文学库/
├── assets/              # 媒体资源层：图片、PDF、附件
├── raw/                 # 写作区（只读权限，仅允许更新 frontmatter）
│   ├── 诗集/
│   │   ├── 中文/        # 中文诗源文件
│   │   ├── en/          # 英文诗源文件
│   │   └── freestyle/     # 随吟写作区：一行一首；多行随吟以双换行/-- 分隔
│   ├── 文选/            # 散文/故事/思考文章
│   ├── 专辑/            # 特定主题/事件的混合文体合集（中英文不拘）
│   └── 收藏/            # 自媒体/书籍摘录（只收集，不归档）
├── wiki/                # 输出层
│   ├── 归档/
│   │   ├── 诗集/
│   │   │   ├── 中文/{theme}/xxx.md     # 语言 → 主题
│   │   │   ├── en/{theme}/xxx.md
│   │   │   ├── {year}/中文/{theme}/xxx.md  # 年份 → 语言 → 主题
│   │   │   └── {year}/en/{theme}/xxx.md
│   │   ├── 文选/{theme}、{year}/       # 同理
│   │   └── 专辑/{theme}、{year}/       # 专辑整体保留，拆分片段入诗集
│   ├── 赏析/            # 每篇对应一首已归档作品（poem 字段关联）
│   ├── 年选集/          # 年度整编（/// 分隔，首行标时间）
│   ├── index.md         # 文学总目
│   ├── log.md           # 操作日志
│   └── .meta/           # 元数据层（可选）
└── 诗云/                # 可视化服务（详见 docs/诗云连接与开发.md）
```

## 3. Frontmatter 规范

### 中文诗词

```yaml
---
title: "诗题"
type: poem
lang: zh
author: 龙川武生
theme: 情          # 8 主题之一
form: 近体诗       # 5 体裁之一
created: 2026-06-20（丙午年五月廿四）
last_modified: 2026-06-20（丙午年五月廿四）
tags: []
---
```

### 英文诗词

```yaml
---
title: "Poem Title"
type: poem
lang: en
author: 龙川武生
theme: love
form: 英文诗
created: 2026-06-20      # 英文只用公历
last_modified: 2026-06-20
tags: [love]
---
```

### 文选 / 摘录 / 专辑 / 赏析

```yaml
# 文选（type: essay）——与中文诗相同，不含 form
---
title: "文章标题"
type: essay
lang: zh
theme: 人生
created: 2026-06-20（丙午年五月廿四）
---

# 收藏摘录（type: clipping，不参与归档）
---
title: "摘录标题"
type: clipping
lang: zh
source: "书名/文章名/作者"
collected: 2026-06-20
---

# 专辑（type: collection）
---
title: "For Senior Wu"
type: collection
lang: mixed
theme: 情
subject: "senior Wu"
date_range: "2026-06-03 ~ 2026-06-09"
created: 2026-06-03
last_modified: 2026-06-20
---

# 作品赏析（type: review，置于 wiki/赏析/）
---
title: "《边城月》赏析"
type: review
poem: "边城月"            # 必须与归档诗歌的 title 完全一致
theme: 情
rating: ★★★★☆
best_line: "爱恨摇年华已悄"   # 诗云「赏」优先展示此句
created: 2026-08-16
---
```

### 时间戳格式

| 类型 | 格式 | 示例 |
|------|------|------|
| 中文（lang=zh） | `YYYY-MM-DD（干支年X月X日）` | `2026-06-20（丙午年五月廿四）` |
| 英文（lang=en） | `YYYY-MM-DD` | `2026-06-20` |

干支参考：2024=甲辰，2025=乙巳，2026=丙午，2027=丁未，2028=戊申

## 4. 主题与体裁

### 8 个预设主题

| 主题 | English | 典型内容 |
|------|---------|---------|
| 情 | Love | 爱情、亲情、友情 |
| 哲学 | Philosophy | 存在、意义、思辨 |
| 人生 | Life | 成长、感悟、际遇 |
| 自然 | Nature | 山水、季节、景物 |
| 社会 | Society | 时政、民生、观察 |
| 历史 | History | 怀古、咏史、记忆 |
| 自省 | Introspection | 内观、反思、独白 |
| 日常 | Daily | 生活琐记、随笔 |

### 5 大体裁（form）

| 体裁 | 结构特征 | 典型示例 |
|------|---------|---------|
| 近体诗 | 五言/七言对句；每行一句（含逗号两半句），行数 2~8；句内前半句 5 或 7 字 | 少年、彩虹 |
| 词 | 标题含词牌（清平乐/扬州慢/破阵子等），句式长短句参差、分段 | 清平乐·再回首 |
| 现代诗 | 自由体，行数字数不固定，无格律约束 | 军训系列 |
| 随吟 | 标题含"随吟"，或 freestyle 写作区拆出，多为一句/一段瞬间感怀 | 随吟(26年) |
| 英文诗 | lang: en，按英文习作（分段、标点、换行） | Idealist、Autumn Leaves |

**为什么 form 重要**：诗云「赏」按体裁选取展示片段——近体诗按行取整句、词/现代诗/英文诗按空行分段取整段、随吟按段取整句。

## 5. 工作组与方法（Agent Skill）

仓库自带三套可复用工作流，适合与 AI Agent（Claude Code / Opencode 等）配合：

### /ingest —— 归档流水线
扫描 raw 写作区 → 验证/补全 frontmatter → 判定主题与体裁 → 双维度复制到 wiki/归档/ → 更新总目与日志。

特殊处理：
- **随吟拆分**：freestyle/ 按首拆分（默认一行一首；多行为一次随吟以双换行或 `--` 分隔），命名 `{源基名}-{序号}.md`，`form: 随吟` 固定
- **专辑拆分**：按日期标记拆成片段，按语言归类入诗集；专辑整体保留在 `wiki/归档/专辑/`
- **英文语法审查**：英文诗逐行检查主谓一致/时态/冠词/单复数等，发现问题先报告经确认再改
- **冲突处理**：归档目录同名且内容不同时暂停询问（覆盖/重命名/跳过）

### /query —— 文学检索
永远先读 `wiki/index.md` 定位 → 按主题/年份/语言/意象/情感等维度深读归档 → 以 `[[双链]]` 引用格式回答；有价值的综合分析可固化为 wiki 页面。

### /lint —— 健康巡检
四步扫描：源文件 ↔ 归档比对（未归档作品）、index 双链 ↔ 归档比对（死链/孤岛）、frontmatter 格式检查、干支纪年核对；只读扫描，报告后经确认才修复。

## 6. 日常维护清单

| 频率 | 动作 |
|------|------|
| 每次创作 | 在 raw/ 对应目录建文件，写好 frontmatter（theme/form/时间戳），正文只写不改 |
| 随手 | 运行 `/ingest <文件>` 将新作归档入 wiki/ |
| 定期 | 运行 `/lint` 体检：未归档、死链、孤岛、干支错误 |
| 季度 | 整理 `wiki/年选集/{year}.md`（`///` 分隔整编，可由脚本生成） |
| 赏析 | 为满意作品在 `wiki/赏析/` 写赏析（`poem` 字段关联归档 title），诗云「赏」自动展示 |

## 7. 与诗云的数据契约

诗云只依赖两个目录、一个规范：

| 输入 | 位置 | 读取内容 |
|------|------|---------|
| 诗集 | `wiki/归档/诗集/` | frontmatter（title/year/lang/theme/form/created）+ 正文（lines/stanzas 解析） |
| 赏析 | `wiki/赏析/` | frontmatter（poem/theme/rating/best_line）+ 正文 |

- 重复文件去重：以 `title|lang|首行` 为键（主题维度与年份维度各有一份，只保留一个）
- 分组：`form` 驱动「赏」的片段选取；英文诗 `lang: en` 主题用英文值（如 `nature`）
- 前端词云分词：优先命中 `诗云/data/poem-words.json` 词典，未命中回退二元组合

## 8. 常见问题

**Q：raw 不是应该移动吗？为什么是复制？**
个人创作源文件是唯一的，移动有风险；归档区丢了一份随时可从 raw 重建。

**Q：同一首诗为什么在归档区有两份？**
主题维度回答「我写过哪些主题」，年份维度回答「某年写了什么」，牺牲一点磁盘换检索自由。

**Q：`wiki/收藏/` 是什么？**
摘录（clipping）只收集不归档，不属于 /ingest 扫描范围，也不进入诗云。

**Q：赏析的 `poem` 字段必须和诗歌 title 一模一样？**
是的。诗云按 `poem` 字段关联（唯一例外：重名「无题」时按 theme 区分）。改名诗歌务必同步改赏析。
